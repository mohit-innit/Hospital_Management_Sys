# Hospital Management System

A simple Hospital Management System developed in C as a college project. The program helps manage basic patient information using structures, arrays, and functions.

# Features

- Register new patients
- Search for patients
- Update existing patient details
- Display all registered patients
- Count the number of admitted patients
- Validate user input to reduce invalid entries
- Restrict gender input to the permitted options
- Check patient details such as name, age, and admission status

# Concepts Used

This project demonstrates the following C programming concepts:

- Structures (`struct`) to store patient information
- Arrays to maintain multiple patient records
- Functions to divide the program into smaller, reusable tasks
- Pointers where required for passing and modifying data
- Conditional statements for decision-making
- Loops for menus and record processing
- String handling for patient names and searches
- Input validation to handle incorrect user entries

##How It Works


Users can register patients, search for existing records, update patient information, display all patients, and count admitted patients.

Patient information is stored in structures and managed using arrays during program execution.
